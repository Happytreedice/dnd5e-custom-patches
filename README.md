Кастомные расширения, оптимизации и исправления для системы **D&D 5e** в **Foundry Virtual Tabletop** (v13–v14).

---

## 🌟 Основные возможности

### 1. ⚔️ Атаки толпы (Handling Mobs / DMG)
- Полная реализация правил DM Guide по атакам групп существ (Handling Mobs).
- Интерактивный диалог: выбор количества атакующих, целевого КД и автоматический расчёт гарантированных попаданий без десятков отдельных бросков.
- Специальный подтип сообщений чата (`mobAttack`) с компактным отображением результатов и броском суммарного урона.

### 2. 🕊️ Правила C7d20 (Общая Надежда / Communal Hope)
- Поддержка пула **Communal Hope** для всей группы.
- Интеграция счётчика Надежды в шапку листа персонажа.
- Регистрация правил C7d20 в конфигурациях системы `dnd5e`.

### 3. 🗡️ Свойства оружия и заклинаний
- **Slayer (Убийца):** новое свойство оружия с выбором типа цели (гуманоиды, нежить, драконы и др.) и настройкой урона.
- **Weapon Damage в заклинаниях:** интеграция атак оружием в заклинания («Клинок зелёного пламени», «Громовой клинок» и др.). В карточке чата появляется выпадающий список экипированного оружия заклинателя с кнопками атаки и автоматическим суммированием урона заклинания и оружия.
- **Light Source:** расширенная настройка источников света для предметов и заклинаний.

### 4. 📖 Книги заклинаний в экипировке (Equipment Spellbook)
- Возможность привязывать заклинания напрямую к предметам экипировки (книги заклинаний, свитки, артефакты).
- Интеграция настроек книги заклинаний во вкладку деталей предметов типа `equipment`.

### 5. 🎭 Значки активных эффектов на токенах
- Опция показа значков на токенах для всех наложенных эффектов (включая непереносимые эффекты без фиксированной длительности).
- Автоматическое восстановление отображения значков эффектов, повреждённых при миграциях DAE.

### 6. 🎓 Улучшение фильтра заклинаний при повышении уровня
- Исправление бага открытия браузера компендиумов при повышении уровня: предотвращает показ заговоров (круг 0) в шаге выбора заклинаний 1+ круга, если выбор заговоров вынесен в отдельное продвижение.

### 7. 💥 Критические попадания для активности «Спасбросок»
- Добавление полей и логики критических попаданий (разрешение крита и бонусный критический урон) для активностей типа «Спасбросок» (актуально для заклинаний вроде «Громовая кара» / *Thunderous Smite*).

### 8. 🛡️ Защита подсказок от гонки (Tooltip Guard)
- Устранение системной ошибки `Cannot read properties of null (reading 'dataset')` при быстром перемещении курсора по карточкам и ссылкам в чате и листах.

### 9. 🎨 Светлая тема журнала чата dnd5e
- Стильное и контрастное светлое оформление карточек журнала чата по умолчанию.

### 10. ⚡ Оптимизации движка и утилиты
- Динамический расчёт формул вида `[[formula]]` при создании активных эффектов с учётом `spellLevel` и масштабирования.
- Утилита починки идентификаторов продвижений (`tools/repair-advancement-ids.mjs`).
- В roll data актёра присутствуют все статусы (`@statuses.deafened` = 0, когда статуса нет): стоковые эффекты вроде «Эхолокации» больше не падают с «Unable to replace all data references».

## 📦 Установка

### По ссылке на манифест (Manifest URL)

1. Откройте Foundry VTT и перейдите на вкладку **Настройка дополнений** (Add-on Modules).
2. Нажмите кнопку **Установить модуль** (Install Module).
3. В поле **Ссылка на манифест** (Manifest URL) вставьте:
   ```text
   https://github.com/Happytreedice/dnd5e-custom-patches/releases/latest/download/module.json
   ```
4. Нажмите **Установить**.
